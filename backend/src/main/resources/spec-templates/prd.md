## 4. 승인 기준 (Acceptance Criteria)

승인 기준 하나는 `### AC-번호: 이름` 하나다. 바로 아래 줄에 시스템이 지킬 동작을 한 문장으로 쓰고 끝에 `(SHALL)`을 붙인다. 하지 말아야 할 동작이면 `(MUST NOT)`을 붙인다. 그 아래 `#### 시나리오: 이름`을 하나 이상 두고 `- 조건:`(생략 가능), `- 동작:`, `- 결과:`를 한 줄씩 쓴다. 결과는 참/거짓으로 판정할 수 있어야 하고 "적절히", "빠르게" 같은 말은 수치나 관찰 가능한 결과로 바꾼다. AC 번호와 이름, 시나리오 이름은 기술문서와 다음 버전이 참조하므로 승인 뒤에는 바꾸지 않는다.

### AC-1: (예: 초안 생성)
로그인한 PLANNER가 `title`과 `body`를 보내면 시스템은 DRAFT 상태 문서를 만들어야 한다(SHALL).

#### 시나리오: 정상 생성
- 조건: PLANNER로 로그인했다
- 동작: `title`과 `body`를 보낸다
- 결과: DRAFT 상태 문서가 생성된다

#### 시나리오: 권한 없음
- 조건: VIEWER로 로그인했다
- 동작: `title`과 `body`를 보낸다
- 결과: 403이 반환되고 문서는 생성되지 않는다

### 승인 기준 명확성 점검

- [ ] 모든 AC에 시나리오가 하나 이상 있고, 각 시나리오에 동작과 결과가 있다

- [ ] AC끼리 서로 모순되지 않는다
